# EverUs Landing Page

Landing page mobile-first cho EverUs, dựa trên visual direction được cung cấp:
- pastel pink / lavender / lemon / mint
- glassmorphism nhẹ
- rounded cards
- mascot hai cuộn len
- tone kể chuyện, ấm áp, dành cho các cặp đôi trẻ Việt Nam

## Chạy local
Mở `index.html` trực tiếp trên browser, hoặc:
`python3 -m http.server 8000`

Sau đó truy cập `http://localhost:8000`.

## Thay CTA
Nút `Thử EverUs ngay` hiện để `href="#"`. Có thể thay bằng link prototype/app thật.

## Asset
`everus-mascot.png` được crop từ visual EverUs được cung cấp.
